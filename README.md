# puff-fluffy-adventure
> A cozy 2D web game built with HTML5 Canvas and Vanilla JavaScript featuring a cute pet-fetching mechanic.
# PUFF: The Fluffy Adventure


## Features

* **Player Movement:** Control the character smoothly across the screen using `WASD` or arrow keys.
* **Moving Entities:** Automatic spawning of collectible items (with different point values) and free-roaming enemies/bugs.
* **Pet Communication / Fetch Mechanic:** Click anywhere on the canvas to command your loyal pet to run, fetch items, or hit enemies, and return back to you!
* **Cozy Aesthetic:** Clean pastel UI design paired with crisp HTML5 Canvas rendering.

## Future Implementation & Roadmap

If time permits or for future development iterations, the following features are planned to elevate the game from a prototype to a polished indie web experience:

* **Customization System:** Allow players to unlock and choose different skins/accessories for the character and pets (e.g., hats, custom colors).
* **Sprite Sheet Animation:** Replace current emoji placeholders with custom 2D pixel-art sprite sheets and frame-by-frame animations for smooth walking, running, and fetching actions.
* **Audio & Sound Effects:** Integrate the Web Audio API to add cozy background music, interactive sound effects (fetching barks, item pickup chimes, and UI clicks).
* **High Score Persistence:** Utilize browser `localStorage` or a lightweight backend database to save players' high scores and personal records across sessions.
* **Mobile & Touch Support:** Optimize touch event listeners so mobile and tablet users can play seamlessly on-the-go.
